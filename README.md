# Fast Click — jeu de réaction

Ouvrez `index.html` dans votre navigateur (double-clic ou `Ctrl+O`).

- Démarrez le jeu avec le bouton *Démarrer*.
- Une image (lettre) apparaît; appuyez sur la touche correspondante le plus rapidement possible.
- Le temps (en ms) s'affiche et le meilleur temps est conservé pendant la session.

Fichiers principaux:

- [index.html](index.html)
- [style.css](style.css)
- [script.js](script.js)
